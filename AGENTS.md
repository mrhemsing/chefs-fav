# Chef’s Fav project

- Scope: British Columbia only; Mates on Crates by Chef’s Favourite. Exclude each guest’s own/current affiliated venues from that guest’s recommendations. Show restaurant affiliation under the chef portrait without claiming every chef is an owner.
- Preserve source, evidence type and wish-list status. Expanded blog lists include off-camera extras and are not proof of video review. Do not label ASR as a verified quote.
- `data/` holds research; `public/map-data.json` is generated by `scripts/prepare-map.py`. Runtime is Vite + Leaflet. Update both research and generated app data when appropriate.
- Keep raw source content, audio, transcripts, caches and credentials out of git (`.cache/` is ignored).
- Never invent coordinates. Retain uncertain places in the list without pins. Review geocoder matches for similarly named businesses and incorrect branches.
- `npm run build`, `python scripts/validate.py`, and `node scripts/ui-smoke.mjs` are relevant checks. Dev port must be 3000. Mobile checks include 390px and 320px, search, chef/category filters, save, modal closing and list/map switching.
